# Clip Studio for Windows

This repository distributes Clip Studio installers and application updates. Development remains in STL Workshop; this repository is not a source-project handoff.

Download Windows installers from [Releases](https://github.com/SEBtheLEB/clip-studio/releases). Once installed, use **Updates** inside Clip Studio to check for new versions. Only published releases appear in the updater.

Clip Studio includes video import, clipping and review workflows, and a custom editor with direct text fields and video, music and sound-effect lanes. STL Workshop is not required on the recipient’s computer. Users configure their own provider connections. Optional Local AI setup needs Python 3.11 or 3.12 and downloads additional tools/models.

Application updates preserve the local Clip Studio workspace. Developer build controls and the full STL editor interface are excluded from the distributed application.
